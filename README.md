# 漫剧工坊作品页

这是用于 AI 产品实习投递的静态作品网站。

## 内容

- 一页式产品案例主页
- 真实总控台、分镜、素材、生图、配音、视频和剪辑截图
- 6 张实际生成镜头
- 3 件 AIGC 动态影像作品
- 角色三视图
- 6 张实际生成镜头
- 完整产品案例阅读页

## 隐私

- 不包含 SQLite 数据库
- 不包含 API Key、Token 或账号信息
- 不包含完整音色工具包
- 不包含作品源目录和个人聊天文件
